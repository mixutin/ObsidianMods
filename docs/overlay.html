F8 NATIVE IN-GAME MENU

Know what actually loaded.

Obsidian Native Runtime renders the menu directly into Dungeons II's DirectX frame. Press F8 and the UI appears inside the game—no companion window and no alt-tab.

STATUS AT A GLANCE

Press F8. See the truth.

The in-game menu distinguishes enabled, disabled, active and loader-failed states. PAK/IoStore mods are reported separately from runtime-loader mods.

Native DirectX rendering

The private runtime hooks D3D12/D3D11 presentation and draws Dear ImGui inside the game's own swap chain.

F8 toggle

Open or close Obsidian without leaving the game; input is captured by the menu while it is open.

Independent diagnostics

The native runtime does not depend on UE4SS, so it can still report UE4SS startup failures.
